# Humanities Discipline Pack

Pack ID: `humanities`

Status: **validated-native**

Use for history, philosophy, literature and cultural interpretation.

## Native learning grammar

- establish source/context before interpretation;
- distinguish `fact`, `source claim`, `interpretation`, and `evaluation`;
- compare sources through explicit lenses rather than cherry-picking quotations;
- map argument relations without pretending an argument diagram proves truth.

## Native widgets

- `source-comparison-lab`
- `argument-map-lab`
- annotation / timeline remain useful supporting widgets.

## Quality gate

- Every compared source declares a real `sourceRef` from course sources and a `textStatus` (`quote`, `paraphrase`, `summary`, or `translation`).
- Sources include context and perspective; every comparison lens has analysis for each source.
- Evidence nodes in argument maps require source provenance.
- Interpretive disagreement is allowed; feedback should ask whether the interpretation is grounded, not whether it matches a hidden single answer.


## animation profile

Animate chronology only when temporal change is the target; do not turn chronology into unsupported causality.
