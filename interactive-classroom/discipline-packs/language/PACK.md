# Language Discipline Pack

Pack ID: `language`

Status: **validated-native**

## Native learning grammar

Prefer explicit meaning/form/use cycles rather than isolated memorization:

1. explain the target meaning and discourse use;
2. contrast the target form with a plausible competing form;
3. practice in context with `cloze-lab`;
4. reconstruct syntax with `sentence-builder-lab`;
5. inspect structure with `grammar-tree-lab` when grammar relations are the learning target;
6. use annotation/dialogue for reading and pragmatic interpretation.

## Native widgets

- `cloze-lab`
- `sentence-builder-lab`
- `grammar-tree-lab`

Reading/grammar/writing can be deterministic offline. Listening requires real embedded audio. Pronunciation scoring requires a real speech engine and is not available in the strict offline default.

## Quality gate

- Cloze answers must be explicit and allow justified variants rather than arbitrary string matching.
- Sentence builders must have stable token IDs and explicit accepted orders.
- Grammar trees need one root, valid parent links, roles and explanations.
- Explain why an answer works; do not reduce language learning to correctness ticks.
- Preserve register, context and meaning. Do not teach one stylistic preference as a universal grammar rule.


## animation profile

Use animation sparingly; native sentence/grammar activities are usually more faithful than decorative motion.
