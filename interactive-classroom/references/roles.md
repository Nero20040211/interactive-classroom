# Generation-Time Roles 

These roles improve classroom generation. They are not live agents in the offline browser.

## Teacher

- defines conceptual sequence;
- explains with minimal jargon;
- chooses examples/contrasts;
- connects scenes to objectives;
- synthesizes after learner activity.

Teacher does not self-certify mastery.

## Curious Student

- asks competent-beginner questions;
- flags assumed prerequisites;
- identifies ambiguous terms;
- proposes “what if” cases.

Turn outputs into dialogue prompts, hints, FAQ branches or labels.

## Skeptic

- challenges causal claims;
- finds missing boundary conditions;
- tests counterexamples;
- detects overclaiming and false dichotomies.

Turn outputs into contrast cases, warning callouts or debate branches.

## Evidence Reviewer

- distinguishes source-backed fact from analogy/illustration;
- checks source fidelity;
- flags uncertainty/contestation;
- recommends evidence notes.

If no source supports an empirical detail, do not fabricate certainty.

## Examiner

- maps questions to objectives;
- creates misconception-specific distractors;
- maps wrong answers to remediation;
- includes transfer, not only recognition;
- avoids ungradable offline scoring.

## Visual Director

- chooses whether an idea deserves dialogue, whiteboard, graph, timeline, simulation or plain text;
- protects cognitive load;
- checks consistency of role identity, navigation, labels and interaction grammar;
- ensures animation is skippable and not decorative;
- checks visuals have text alternatives.


## Discipline Specialist

- validates notation, terminology, units and domain conventions;
- checks whether the selected widget/assessment matches the discipline;
- flags unsafe or misleading simplifications;
- distinguishes illustrative models from validated domain models.

For mixed courses, state which discipline profile is primary.

## Moderator (optional)

- frames multi-perspective discussion;
- sequences viewpoints;
- highlights unresolved disagreement;
- asks the learner to commit before synthesis.

## Recommended delegation

For a substantial course:

- Teacher: learning map + draft sequence.
- Curious Student: confusion points.
- Skeptic: weaknesses/counterexamples.
- Evidence Reviewer: grounding audit.
- Examiner: objective → assessment/remediation map.
- Visual Director: visual/interaction map + UX audit.
- Discipline Specialist: domain convention + representation audit.
- Main Codex agent: reconcile and compile.

Do not have multiple roles edit the same final HTML concurrently.
