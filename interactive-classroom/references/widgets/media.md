# Widget: media

Use only when actual local/embedded audio, image or video is available.

Strict offline mode permits `data:` URIs or other self-contained embedded bytes.

Required:
- accessible label/transcript/caption where applicable;
- learner task tied to the media;
- deterministic follow-up or self-rubric;
- no remote media dependency.

Do not synthesize or pretend to include audio/video when none exists.
