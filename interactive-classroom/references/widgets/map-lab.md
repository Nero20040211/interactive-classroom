# map-lab — Geography 

A strict-offline spatial reasoning lab. Use only embedded, verified geographic points/features with provenance. Canonical supports `equirectangular` or `mercator`, graticules, category filters, point selection, coordinate inspection, two-point great-circle distance and initial bearing.

Required for validated-native Geography: `verified:true`, structured `provenance`, `coordinateSystem`, `projection`, `scaleNote`, stable point IDs with lon/lat/sourceRef, and an explicit learning task that asks for spatial comparison rather than mere lookup. Political/admin boundaries require an explicit boundary policy; if boundaries are not necessary, prefer point/physical data to avoid implying a political stance. Never invent routes, boundaries or coordinates.
