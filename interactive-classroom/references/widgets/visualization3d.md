# Widget: visualization3d

Use when spatial structure is central: molecule, anatomy, geometry, solar system, architecture, vector/spatial model.

Offline uses a lightweight SVG projection of authored 3D points/edges.

Required:
- labeled elements with stable IDs and x/y/z coordinates;
- rotate X/Y controls and reset;
- selectable elements with details;
- text fallback describing the spatial relationships;
- no claim of physical scale unless data supports it.

For high-fidelity surfaces/meshes, the user must explicitly accept a bundled local rendering library or a larger multi-file artifact.
