# `random-trial-lab`

A local pseudo-random repeated-trial studio for probability/frequency learning.

Required: `theoreticalP` in [0,1], `maxTrials >= 100`, at least two `experimentPrompts`, and a `boundary` explaining finite-sample variability.

Learners change trial count, rerun the experiment and compare a cumulative-frequency curve against the theoretical-probability reference line. A single simulation path is not a proof.
