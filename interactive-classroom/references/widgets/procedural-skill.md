# Widget: procedural-skill

Use for ordered practice: lab technique, maintenance, clinical-skills education, manufacturing, field procedure, workflow mastery.

Required:
- scenario/context;
- ordered steps;
- prerequisites/constraints;
- hazard or critical-step labels when relevant;
- learner commits to the next step before reveal;
- checkpoints and remediation;
- completion debrief.

Educational simulation is not certification. For safety-critical domains, explicitly state that real supervised practice is still required.
