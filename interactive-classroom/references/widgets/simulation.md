# Widget: simulation

Use for a deterministic model where changing parameters reveals a meaningful relationship.

Required:
- question/prediction before manipulation;
- model name and educational purpose;
- parameters with min/max/step/initial/unit;
- visible output;
- assumptions and boundary conditions;
- 1–3 guided experiments;
- interpretation prompt.

Prefer built-in registry kinds: `linear`, `quadratic`, `exponential`, `logistic`, `harmonic`, `projectile`, `normal`, `points`.

Never invent scientific parameters from sources that do not provide them. Label illustrative parameters as illustrative.
