# Learner-facing contract 

Generated HTML is a learning product, not a build report.

Keep `sourceCoverage`, `contentInventory`, internal schema markers, Discipline Pack routing, validation policy and Skill-maintenance policy internal. Learners should see ordinary study language: `学习导览`, `练习`, `过程动画`, `掌握检测`, `参考资料`, `学习反馈`.

Bibliography/citations remain visible when they help provenance. The distinction is: show *where learning claims come from*; hide *how the authoring system validated or routed them*.

When `meta.learnerSurfacePolicy.hideEngineering=true`, strict validation rejects common engineering terms in learner scene content.


## Visual clarity

Learner-facing diagrams and animations must prioritize legibility over density. Do not place long prose labels on top of moving objects. Use fixed explanation rails, adequate canvas margins, and intentional containment zones. If two visual objects overlap only because the layout is crowded, redesign the layout; do not solve it by reducing opacity.
