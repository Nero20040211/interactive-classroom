# Assessment 

Offline assessment must be deterministic and transparent.

## Supported response kinds

### single
One option ID must match the answer set.

### multiple
Compare selected option IDs as a set.

### numeric
Compare a finite numeric value to `answer` with declared absolute or relative tolerance and unit if relevant.

### short
Use normalized exact alternatives only for tightly constrained factual responses. Show accepted forms after submission.

### ordering
Compare item ID order.

### matching
Compare explicit key→value pairs.

### classify
Compare each item with a declared category.

### code-output
Learner predicts output/state; compare to a declared deterministic expected answer. Do not claim code was executed unless it actually was.

### equation-step
Learner selects/arranges the valid next derivation step.

### self-rubric
For explanations, essays, proofs not reducible to exact rules, require learner output first and then reveal a checklist/rubric. This is not AI grading.

## Feedback

For important errors, include:

- why the option is tempting;
- the exact misconception;
- the distinction/rule that repairs it;
- optional remediation scene ID.

## Mastery

Do not rely on recognition only. Include at least one transfer/application task when the objective requires reasoning or skill.
